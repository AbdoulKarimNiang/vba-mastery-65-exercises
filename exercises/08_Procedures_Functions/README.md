# VBA Exercise 8: Procedures Functions

## Objective

Create reusable procedures and functions with parameters

## Files

| File | Purpose |
|------|---------|
| `08_Procedures_Functions_start.xlsm` | Workbook to work in |
| `08_Procedures_Functions_start.bas` | Starting code to import |
| `SOLUTION.md` | Solution and explanation (open only when you're done) |

## How to load the starting code

1. Open `08_Procedures_Functions_start.xlsm` and click **Enable Content** if asked.
2. Press **Alt+F11** to open the VBA editor.
3. **File > Import File...** and choose `08_Procedures_Functions_start.bas`.
4. Complete the `TODO`s, run with **F5**, and save with **Ctrl+S**.

> Event procedures (`Workbook_Open`, `Worksheet_Change`) must be pasted into the
> **ThisWorkbook** or sheet code module, not imported as a standard module.
